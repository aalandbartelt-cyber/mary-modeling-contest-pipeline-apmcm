# Templates

官方模板不复制进 skill，避免版本漂移。使用项目目录中的 2026 版：

- `00_赛题与规则/官方发布/2026年第十六届APMCM…参赛规则.pdf`
- `00_赛题与规则/官方发布/2026论文规范与模板/2026 APMCM Essay format and submission specifications.pdf`
- `00_赛题与规则/官方发布/2026论文规范与模板/2026 APMCM Summary Sheet.docx`（p1 Summary + p2 Contents）
- `00_赛题与规则/官方发布/2026论文规范与模板/2026 APMCM Control Sheet.docx`（单独一页承诺书）
- `00_赛题与规则/官方发布/2026论文规范与模板/APMCM LaTeX 模板/`（`apmcmthesis.cls`, `apmcmthesis.cfg`, `main.tex`, `ControlSheet.tex`, 编译示例 PDF）

官方说明：论文模板**仅供参考，不做强制要求**；Word 或 LaTeX 均可，不熟 LaTeX 不要用（编译错误组委会不解答）。

使用前先跑通模板，删除模板里的中文示例（CJK、公众号图、中文 caption、`cat`/`gongzhonghao` 图），并核对 p1/p2 页眉只有队号、正文起才有 `Page x of y`。
