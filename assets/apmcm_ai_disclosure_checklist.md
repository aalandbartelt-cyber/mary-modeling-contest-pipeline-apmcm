# APMCM AI 工具使用检查清单（2026 官方规定）

> 依据：APMCM 2026 年 11 月《人工智能工具使用规定》。
> 使用 AI 的参赛队必须完成；未使用 AI 的参赛队必须写官方声明。

## 1. 先判断是否“使用了 AI”

- [ ] LLM / 生成式 AI
- [ ] 代码辅助工具
- [ ] 智能数学软件
- [ ] 数据分析与建模软件
- [ ] 翻译软件
- [ ] 自动补全技术
- [ ] 其他 AI 工具

只要用了上述任一工具，就按“使用 AI”执行；不要因为只是翻译/补全/画图而省略。

## 2. 核心独立性

- [ ] 核心模型构建由队员完成
- [ ] 算法设计与求解由队员完成
- [ ] 结果分析由队员完成
- [ ] AI 只用于辅助（检索/语法/debug/可视化/排版等）
- [ ] 队员理解并对 AI 输出负责

## 3. 使用 AI 的交付

- [ ] 正文相应位置有 AI 使用标注
- [ ] References 有 AI 工具条目，格式：
      `[编号]工具名称，版本/型号，开发机构/公司，使用日期。`
- [ ] 官方示例格式已核对：
      `[1]DeepSeek,DeepSeek-R1-0528,深度求索（DeepSeek）,2026-6-12`
- [ ] 已生成 `AI工具使用详情.pdf`
- [ ] 详情说明包含：
      (1) 工具名称和版本
      (2) 使用目的和应用环节
      (3) 关键交互记录（重要提示词与回复）
      (4) 采纳内容和人工修改情况
- [ ] 交互记录真实，不是编造
- [ ] 所有 AI 输出已人工核验/纠正

## 4. 未使用 AI 的声明

- [ ] 在 References 后写官方原句：
      `本参赛队未使用任何AI工具`
- [ ] 没有改写成英文/另一赛事措辞
- [ ] 如果论文正文必须全英文，已向组委会/报名系统确认这句中文声明的放置方式

## 5. 学术规范

- [ ] 所有引用/数据/资料注明出处
- [ ] 无法确认来源的模型/算法/数据已标注说明
- [ ] 没有把 AI 复制的文本当原创
- [ ] 没有编造参考文献/数据/结果
- [ ] 没有把另一赛事 30%/50% AIGC 阈值当作 APMCM 规则
- [ ] 本地 AIGC/PPL 扫描没有当成官方检测结论

## 6. 提交前

- [ ] `AI工具使用详情.pdf` 文件名正确
- [ ] 论文正文标注 / References / 详情说明三者一致
- [ ] 如未使用 AI：官方声明在 References 后
- [ ] 没有遗漏任何实际使用的 AI 工具
- [ ] 不符合规定可能取消评奖资格，已逐项确认
