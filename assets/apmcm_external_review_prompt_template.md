# 外部 AI 独立复核提示词模板（APMCM）

> 用途：请另一个 AI 复核论文/代码是否存在原则性错误时，直接套用本模板生成提示词。
> 原则：让复核方**全量查证**，不是只查已点名的问题；先给结论，再给证据；每条判断落到题面页码、代码文件行号、实验记录或最小反例。

```text
请你作为独立的建模评审和实验复核人，审查本论文第 X—Y 问（或全文）是否存在原则性错误。
如果有，判断哪些结果受影响，并给出能实际执行、能验证修复效果的方案。
之前的 AI 结论可以被推翻；我需要你自己查证。

工作区：<路径>。先读 AGENTS.md 和指定 skill，再看：
- 官方题面：<路径>（以官方原文为准）
- 当前论文：<路径>
- 交接/已有核查记录：<路径>（只是线索，不是结论）

先独立列出本题必须满足的条件，再定位代码和记录。即使已有测试通过，
也要检查测试对象、条件是否与论文结论一致。审查范围是完整解答，
不能只查已经提过的问题。

逐方法核查：
1. 还原每个模型的拟合、选型、阈值确定、首次评估的时间顺序；
   区分“分数已生成”“已查看分数”“分数被用于选型”，只对有记录的事实下判断。
2. 沿实际调用代码追踪一次预测/决策：该时刻可用的信息是否真的可用？
   未来观测用于事后评分是合理的；查它有没有提前进入预测、校准或选样。
3. 核对每个核心数字在什么数据上成立：同一事件是否被重复计数、
   比较双方是否用相同样本、结论是否超出实验支持范围。
4. 逐项核查最优解、现行方案和简单基线：首次评估前有没有已完整固定、
   满足在线信息约束、仍可保留原始成绩的方法？有就指出；没有就说明排除了哪些候选。

优先做能判定问题的复验：保持截至某时刻的历史相同，只改变仍不可见的未来，
检查更早的预测/决策是否改变。不要一边查看测试分数一边决定修复方案。
先交付独立审查和方案，保留原始记录与现稿。

最后用中文直接回答：
- 已证实的原则性错误有哪些？哪些已修复、仍存在、证据不足？
  把论文表述错误和算法/评估错误分开。
- 逐方法结论表：方法或结论｜判定｜直接证据｜受影响的成绩或图表｜处理办法。
  每个重要判断引用题面页码、代码文件及行号、实验记录或最小反例。
- 对每个仍存在的错误：首选修复方案（改哪里、重跑什么、怎样验收、哪些结果可保留）。
  现有材料补不出的，说明缺哪项证据、什么新数据或官方确认才够。
- 如果今天提交，最大的实质风险是什么？最值得先做哪一件事？

先给结论，再给证据。措辞直接，能量化就给数字；
不要用“证据有限”“仅作参考”这类笼统说法代替判断。
```

**交接文档配套**：复核入口最好附一份交接文档——题面原文位置、两问/各问的评估时间线、已修复代码位置（文件+行号）、已通过实验、待判断问题、复现命令；所有文件链接逐个点开验证过再交付。
