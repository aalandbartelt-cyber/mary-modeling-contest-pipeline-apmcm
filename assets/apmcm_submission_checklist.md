# APMCM 提交检查清单

## A 首页/目录/页数

- [ ] p1 = Summary Sheet（Team Number / Problem Chosen / `2026 APMCM summary sheet` / Summary / Keywords）
- [ ] p2 = Contents（目录，单独一页）
- [ ] 正文从 Contents 后开始，页码从 1 重新开始
- [ ] 正文 ≤25 页（Summary/Contents 不占 25 页；附录不限）
- [ ] 页眉只含队号+页码：p1/p2 只有 `Team # <队号>`，正文起左队号 + 右 `Page x of y`
- [ ] `Page x of y` 的 y 由模板 `LastPage` 生成（正文+附录），没有手写 `of 25`
- [ ] 无姓名/学校/指导教师/邮箱/学号
- [ ] 报名系统题号 = 论文题号 = 文件名首字母

## B 英文

- [ ] 正文无中文
- [ ] 图题/表题/图例/坐标轴无中文
- [ ] 无全角标点
- [ ] 术语统一
- [ ] Summary 350–450 words；每问 2–3 个数字
- [ ] Summary 每问有数字

## C 图表/公式

- [ ] 图/表/公式编号连续
- [ ] 正文引用一致
- [ ] 图题在图下、表题在表上
- [ ] 表不跨页；图题同页
- [ ] 灰度可辨
- [ ] 单位英文

## D 参考文献/附录

- [ ] 正文方括号编号，按首次引用顺序
- [ ] 无僵尸文献
- [ ] 书籍条目带起止页码；期刊带卷号/页码；网络资源带访问日期
- [ ] 附录有软件名 + 全部源代码
- [ ] 源代码保留到获奖名单公布（组委会可能测试）
- [ ] 代码路径与支撑包一致
- [ ] 附录代码零中文（无 SimHei/中文注释/中文字符串）、零个人绝对路径（无 `C:/` `D:/` `Desktop` `/home/xxx`），全文 grep `SimHei|SimSun|C:/|D:/|Desktop|/home/` 零命中
- [ ] 附录代码可运行/可编译

## E 提交件

- [ ] 论文名 = `#***.pdf`（题号+队号），例 `Aapmcm2630001.pdf`
- [ ] Control sheet = `#***cns.pdf` 或 `.jpg`，单独一页、三人签名、未混入论文
- [ ] 承诺书法务条款核对：非原创图/表/照片**在其出现位置**标注引用（不仅是文献列表）；直接引语有引号+出处——签字即担责，缺签全队取消资格
- [ ] 支撑材料仅在题面明确要求时提交；命名 `#***fj.rar/.zip`
- [ ] 支撑包无原始数据、无身份信息、无缓存/虚拟环境
- [ ] PDF 元数据干净
- [ ] 干净环境打开 PDF 一次
- [ ] 提交到 https://www.saikr.com/vse/apmcm26 ，论文+承诺书同时交
- [ ] 提前 ≥30 分钟—1 小时提交（上传耗时，卡点会失败）
- [ ] 若重传：已点右下角“提交电子档”，否则不更新
- [ ] 如走备用邮箱：此前未在赛氪成功提交；全部文件一封邮件、一个压缩包；每人只发一次

## F 写作/证据

- [ ] 每问有 Direct answer / 明确结论
- [ ] Summary 每问有方法+数字+边界
- [ ] 问题重述不是抄题；至少一个歧义处理
- [ ] 每条关键假设有依据/范围/失效影响
- [ ] 每问有基线/验证/敏感性或失败案例
- [ ] 数字在 summary/正文/表/图/CSV 一致
- [ ] 摘要/正文核心数字与附录对照、敏感性、负对照无矛盾
- [ ] 绝对差/相对百分比/百分点没有混用
- [ ] 同一评估口径全文只有一套名字，且正文有评估协议表（Protocol|Evidence|Interpretation）；每个报出的分数带身份标签（first test / validation / reevaluation 随行注明）
- [ ] 最优解不是未标代价的退化解（预约最小值、购买 0 等）
- [ ] 附件口径已审计：导出参数/锚点量级/年份覆盖/哨兵值核对过，数据说明节写明
- [ ] 题面给的锚点数字已用模型复现；参数校准有依据（自然实验/文献）
- [ ] 多问共享同一组参数与情景贯穿；做不完的问写明取舍逻辑
- [ ] 政策/方案结论明确敢下判断，不骑墙
- [ ] 若题面要求非技术信件/短文（给公司/市民/UN），受众、篇幅、口吻符合要求，不堆公式
- [ ] 题面明分值的高分题投入与分值匹配
- [ ] 每个结果页有编号发现句（名字+数字+机制）；每问结尾有 Conclusion for Question N
- [ ] 关键结果表带解读列或紧随解读段；图题是描述性短语，结论在正文
- [ ] 参数有"值+出处+论证"校准块；假设分全文级+模型级两层；核心公式有白话释义
- [ ] 拟合参数值/阈值打印到正文（值 + (rounded) + 口径限定句）；公式后跟 Here 段逐符解释+拟合口径+适用范围

## G 图表/排版

- [ ] 图内最终字号 ≥8 pt（至少 7 pt）
- [ ] 图例/单位/坐标轴可独立读懂
- [ ] 正文没有纯图片页/大段空白
- [ ] 核心结果在正文，完整表/过程图在附录
- [ ] 技术路线图不打断正文段落
- [ ] 三维/仿真图注明 kinematic simulation

## H AI/诚信（2026 官方规定）

- [ ] 已判断是否使用 AI（LLM/生成式/代码助手/智能数学/数据分析/翻译/补全）
- [ ] 核心模型构建、算法设计与求解、结果分析由队员独立完成
- [ ] 使用 AI：正文相应位置有标注
- [ ] 使用 AI：References 有工具条目，格式 `[编号]工具名称，版本/型号，开发机构/公司，使用日期。`
- [ ] 使用 AI：已提交 `#***ai.pdf`（工具/版本、用途/环节、提示词与回复、采纳与修改）
- [ ] 未使用 AI：References 后写官方原句 `本参赛队未使用任何AI工具`
- [ ] 四处留痕一致：正文标注 / References 条目 / `#***ai.pdf` / 文末或声明处
- [ ] AI 使用阐述均为队员口径，无擅自扩写；详情 PDF 未被擅自读写
- [ ] 没有把另一赛事 30%/50% 阈值或 AI 报告模板当 APMCM 规则
- [ ] 所有 AI 辅助内容已人工核验；无编造引用/数据/结果
- [ ] 查重红线：自建库相似度 >30% 判作弊，取消相似论文资格（不与其他队共享文稿/代码）
- [ ] 摘要页/正文无个人信息（出现最高只获成功参赛奖）
- [ ] Control Sheet 三人签名均为英文签名
- [ ] 不符合规定可能取消评奖资格

## I 在线信息/盲测纪律（按时刻决策的题）

- [ ] 每个预测/决策规则有“决策时刻可用信息清单”
- [ ] 做过未来扰动审计：改未来、历史不变，决策不改变
- [ ] 官方测试集 freeze 之后才打开；评估历史有日志（生成/查看/用于选型分开记）
- [ ] 事后校准只用了事后数据，没有回灌进预测或选样
- [ ] 事件/窗口类指标有同速率平凡对照，且模型胜过它
- [ ] 逐时刻辨识与窗口命中两个口径都报了
