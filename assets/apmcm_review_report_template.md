## 1. P0 — cannot submit

- [ ] Wrong problem number / team number / file name
- [ ] Main body >25 pages
- [ ] Page 1 not summary / page 2 not contents
- [ ] Header missing Team # / Page x of y
- [ ] Chinese in body/figures/tables
- [ ] Name/school/adviser/email in paper
- [ ] Control sheet missing signature or placed inside paper
- [ ] Appendix code / support package inconsistent or not runnable
- [ ] PDF metadata contains identity

## 2. P1 — affects score

- [ ] Summary lacks numbers or disagrees with body
- [ ] Figure/table numbering or references wrong
- [ ] No stability/sensitivity evidence
- [ ] Strengths/weaknesses are generic
- [ ] Long sentences / terminology drift
- [ ] Zombie references / wrong citation format
- [ ] Figure text too small or Chinese

## 3. P2 — polish

- [ ] TOC hierarchy
