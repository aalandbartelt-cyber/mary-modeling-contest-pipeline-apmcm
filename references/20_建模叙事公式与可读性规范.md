# 20 获奖论文的建模叙事、公式规范与可读性（实证）

> 样本：四篇 C 题获奖论文正文细读（2022C/2023C/2024C/2025C），页码与节号均可回查。
> 与 `18` 的分工：18 讲"每页放什么"，本文件讲"模型怎么讲、公式怎么排、文字怎么读"。
> 样本为 C 题但叙事/公式规范是通用写作技艺；量子优化题的特化叙事（QUBO 转化章法、步骤复述块、验证句式）见 `25_D题量子优化优秀论文解剖.md`。

## 20.1 四篇的建模思路谱系

### 2025C：框架整合式（最强叙事）

- 一个**命名总框架** SMDEF 统摄五问，分成 3 条 track（Resource / Strategic / Macro），p4 一张三层架构图说清数据→模型→政策输出的流。
- 每问一个**命名专模**：Constrained Armington（Q1）、Dynamic Stackelberg Game（Q2）、Bi-level Policy Simulation（Q3）、Crisis-Aware Forecasting（Q4）、Supply-Side Shock（Q5）。
- 每问内部固定七步：**Core Assumptions → Parameter Calibration（值+出处+区间论证）→ Mathematical Formulation（分 Stage 1/2）→ Simulation Results → Key Insights（编号命名发现）→ Sensitivity（问内小节）→ Conclusion for Question N**。

### 2024C：方法递进式（教科书风也获奖）

- 统计描述 → 因子分析（Correlation/Ridge/LASSO）→ 预测（Time Series → Random Forest → Hybrid 混合模型）→ Q4 升维成博弈模型。
- 方法按问升级：预测问用集成模型体现工作量，政策问用博弈模型体现机制。
- 每个方法配教科书式定义段（"Random forest is a popular ensemble learning algorithm..."）——能获奖但信息密度低，2025C 式更省页。

### 2023C：叙事推理式（轻模型重论证）

- 指标选择先论证再用（"exports serve as a direct gauge of foreign policy impact... hence we select export volume as the yardstick"）；
- 统计工作流驱动：ADF 检验表 → 定差分阶数 → AIC/BIC 定 p,q → 拟合；
- 收尾是碳排放核算 + 政策分析 + Open Letter——模型是叙事的支撑不是主角。

### 2022C：步骤化+多模型对比式

- `Step 1 Model establishment / ⚫Stationary analysis / ⚫Model construction` 实验报告式步骤；
- 假设检验用大白话解读（"p=0.08 < 0.1, reject H0 at 90% confidence, that is..."）；
- 末章把四个模型并列对比（多元回归/ARIMA/RF/GA-BP），用精度评比收尾。

### 通用建模语法（四篇共有）

```text
证据先行（描述统计/检验/图）→ 论证选择（为什么是这个模型/指标）
→ 校准（参数值+出处）→ 形式化（公式/步骤）→ 求解 → 验证 → 解释（发现句）
```

"校准+出处"这一步把机制模型和拍脑袋黑箱分开；四篇全有，形式不同。

## 20.2 公式呈现规范（实测）

1. **编号公式只为真模型核心服务**：数据题 9–34 条即可（见 18.5）；描述统计、定义性公式可内联不编号。
2. **关键公式加 underbrace 项标签**：2025C eq(1) 在两项下标 `Scale Effect`/`Substitution Effect`——机制一眼可读，强烈推荐在核心公式上用。
3. **where 从句给白话**：`Where P̂_i = ln(1+τ_i) (relative price shock)`——符号 + 括号白话释义；2024C 用 `Among them, α>0: market price sensitivity coefficient` 同效。
4. **分阶段呈现**：`The model operates via two stages: Stage 1: Demand Response... Stage 2: Capacity Constraint...`——复杂模型拆命名 Stage/Step（2022C 用 Step 1/⚫，2023C 用 ★Step）。
5. **变量定义三种合法形态**：全局 Notation 表（必选）；节内冒号列表 `SC, SA: Market share...`（2024C 博弈节）；公式后 where 从句。同篇混用可以，但核心变量必须在表里。
6. **Notation 表三列+分组**：`Symbol | Definition | Unit/Context`，按主题分组（Trade & Tariff / Industry-Specific / Macroeconomic）；单位列写 dimensionless、取值范围（`0≤α≤1`）、示例值（`% (e.g., 0.60)`）。
7. **决策链用检验表呈现**：ADF 统计量/p 值表 → 定差分阶数 → AIC/BIC → 定 p,q（2023C Table 3 范式）；检验结论配白话一句。
8. **博弈/离散模型**：策略空间用 bullet 列表（中方两策略/美方两策略），收益矩阵用 2×2 表格，收益函数用 cases 分段公式（2024C 范式）。
9. **参数校准块写法**（2025C 范式，逐参数三件套）：
   `Substitution Elasticity (σ = 5.0): Based on GTAP 10 Database's "Oil Seeds" sector estimates [Cite]. Academia's 3.0–8.0 range, combined with soybeans' high homogeneity, justifies this high elasticity.` = 值 + 出处 + 区间/证据论证。
10. **假设分层**：§2 General Assumptions（全文级，bullet 命名+理由+适用范围"unless specified otherwise"）+ 每问节内 Core Assumptions（模型级，编号列举）。两层都有最稳。

## 20.3 可读性手法（实测句式）

| 手法 | 实例 | 用途 |
|---|---|---|
| 节首命名句 | "We constructed a Constrained Armington Trade Substitution Model, integrating ... to simulate ..." | 每个模型节首 1–2 句说建了什么、集成了什么、为了什么 |
| 路标句 | "The model operates via two stages"、"detailed analysis can be found in Section 4.3.4" | 告诉读者接下来什么结构、去哪看细节 |
| 粗体引导 bullet | `• Rational Behavior Assumption:`、`1. U.S. Export Collapse:` | 每条先粗体命名再解释，可扫读 |
| 图表后必跟解读 | "It can be seen from the table that..."、"Figure 17 illustrates that..." | 证据→文字闭环 |
| 统计白话化 | "p value is less than 0.05"、"reject H0 at 90% confidence, that is, ..." | 检验结论翻译成判断 |
| 图→模型桥 | "Model Implication: ... 'Localization Ratio' is a key strategic variable in our Game Theory model" | 描述性发现接一句"所以它进入模型" |
| 发现命名 | Debt Spiral / USD Paradox / Spillover Dividend | 评委复述时有词（见 18.3） |
| 交叉引用 | "(Section 5.2)"、"(Table 3)"、"(Figure 8.1)" | 密集使用，评委跳转零成本 |

**获奖论文也存在的瑕疵（不要照抄）**：16 位小数结果（`21545123.4782328 kg`，2023C）、语法小错、章节号混用全角标点（`VII、`，2024C）、模糊截图——结构好能兜住小错，但主动制造就没必要。

## 20.4 格式细节（实测）

- **页眉**：每页 `Team # apmcmXXXXXXX`（左）+ `Page x of y`（右），含 Summary 页。
- **Summary 页**：顶部 Team Number/Problem Chosen 双格表 + 居中 `20XX APMCM summary sheet`。
- **章节编号三套都获奖**：纯十进制（4.2.4）、纯罗马（VII.）、罗马主节+十进制子节混排。**篇内一致即可**；2024C 出现 `VII、` 全角顿号是瑕疵不是范式。
- **图题**：图下方居中 `Figure N.N <描述性短语>`（2025C 用章节号 4.3/5.1 编号）；表题在表上方 `Table N <题名>`；2022C 用 `Picture N` 也活下来了，但建议统一 Figure。
- **公式**：居中 display、编号右对齐 `(1)`；编号按全文连续（2024C 到 (32)）或按节（2025C 到 (9)）均可。
- **步骤标记**：`Step 1`/`★Step 2`/`Stage 1/2`/`(a)(b)` 面板标都行，别超过两种标记体系混用。
- **表格**：三线表为主（顶线/标题线/底线）；结果表可加解读列。
- **水印**：官方发布的获奖 PDF 带"亚太地区大学生数学建模竞赛组委会"斜水印——那是官方加的，参赛 PDF 不要自己加水印。

## 20.5 一页纸核对（建模+公式+可读性）

- [ ] 每模型节首有命名句（建了什么+集成什么+为了什么）；
- [ ] 假设两层：全文 General + 模型级 Core，每条命名+理由；
- [ ] 参数三件套：值+出处+区间/证据论证；
- [ ] 核心公式有 underbrace 标签或 where 白话释义；
- [ ] 复杂模型拆 Stage/Step；
- [ ] 决策链有检验表（ADF/AIC 类）+白话结论；
- [ ] Notation 表三列分组、单位/无量纲/范围齐；
- [ ] 每图表后紧跟解读句；描述图后有 Model Implication 桥（如适用）；
- [ ] 关键发现编号+命名（名字+数字+机制）；
- [ ] 无 6+ 位有效数字堆砌；无全角标点；图表编号体系统一。
