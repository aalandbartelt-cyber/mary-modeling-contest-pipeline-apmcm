# 07 APMCM 优秀论文解剖

> 样本：2022—2025 年 APMCM 优秀论文 16 篇（A—E，含 2025 A—D）。
> 目的：把“获奖论文实际长什么样”变成可执行的结构、数字和句式；不是让 2026 照抄旧题。
> 注意：部分优秀论文的正文页数超过 2026 规则写的 25 页，可能是旧规则/页眉计数/附录边界不同；**2026 仍以官方 25 页为准**。

---

## 7.1 量化画像（16 篇）

| 指标 | 最小 | 中位 | 均值 | 最大 |
|---|---:|---:|---:|---:|
| PDF 总页数 | 23 | 35.5 | 41.1 | 76 |
| Summary 词数 | 252 | 387 | 390 | 527 |
| Summary 数字个数 | 5 | 18.5 | 20.4 | 70 |
| 图（最大编号） | 0 | 14 | 14.9 | 34 |
| 表（最大编号） | 0 | 4 | 4.2 | 10 |

**可执行结论**：

- Summary 目标 **350—450 词**，不要 200 词以内，也不要 600+。
- Summary 里 **10—25 个数字** 是常态；每问至少 2—3 个关键结果。
- 正文图 **10—20 张** 是常见量级；图少时表要补，但不能没有证据。
- 表不是越多越好；很多获奖论文只有 3—6 张关键表，其余放图/附录。
- 总 PDF 可以到 30—50 页，但 **正文必须按 25 页控制**；附录不计。

## 7.2 共同骨架

绝大多数获奖论文是：

```text
p1 Summary
p2 Contents
1 Introduction
  1.1 Background
  1.2 Problem Restatement
  1.3 Our Work
2 Assumptions and Justifications
3 Notations
4/5 Model(s) and Solution(s)
  Question 1: ...
  Question 2: ...
  Question 3: ...
  Question 4: ...
6/7 Model Evaluation
  Advantages / Strengths
  Disadvantages / Weaknesses
  Sensitivity / Error Analysis
  Conclusions / Future Work
References
Appendix
```

变体：

- 2024 A：`Introduction → Assumptions → Notations → Model Building and Problem Solving → ...`，问题作为 4.x。
- 2025 C：问题驱动标题（`Question1: ...`、`Question2: ...`），数据预处理单独一节。
- 2025 D：`Problem Restatement → Problem Analysis → Symbol Legend → Basic Assumptions →` 每问模型 → `Advantages and Limitations`。
- 2023 C：政策叙事型，章节标题就是问题结论（`What Will the NEEVs Be...`、`An Open Letter...`）。

**结论**：不要死套“Model/Model/Model”；**问题驱动标题**更常见，也更容易让评委看到“每问都被回答”。

## 7.3 Summary 的获奖写法

### 常见开头

- "The ... problem entails ... This paper develops ..."
- "To quantify ..., this paper constructs ..."
- "This paper addresses multiple issues pertaining to ..."

### 每问段落

获奖论文常用：

```text
For Question 1, we ...
In the first problem, ... is collected/used as ...
For Question 2: Firstly, ... Then, ... Finally, ...
```

每段包含：

1. 方法（模型/算法/数据）；
2. 关键结果（1—3 个数字）；
3. 一句解释/结论。

**不是**只写“我们用了 XXX 模型”，也不是只写“结果很好”。

### 结尾

- 一句总结贡献；
- 一句边界/意义；
- Keywords 3—5 个（有的用分号，有的用换行）。

### 获奖 Summary 的反面

- 纯背景 + 方法名，没有数字；
- 每问只有一句“we build a model”；
- 把正文目录复制进 summary；
- 出现公式/图号/文献角标；
- 中文/全角标点。

## 7.4 正文的获奖写法

### Introduction

- Background 2—4 段：问题重要性 → 现有方法/缺口 → 本文目标。
- Problem Restatement：逐问复述，不要照抄题面；每问 2—4 句。
- Our Work：3—5 句路线图（“We first ... then ... finally ...”），对应目录。

### Assumptions

- 每条假设：内容 + 理由 + 影响（放宽会怎样）。
- 不要写“假设数据真实”这种无信息假设。
- 5—8 条即可；与模型节呼应。

### Model

- 每问先“问题分析”再“模型”；
- 目标/变量/约束/求解器写清；
- 公式前后有解释；
- 参数来源写清（题面/文献/标定）；
- 结果表/图 + 解释 + 与 baseline 对比；
- 每问结尾有小节“Summary/Conclusion for Question N”。

### Model Evaluation

获奖论文几乎都有：

- Advantages/Strengths（3—5 条，带证据）；
- Disadvantages/Limitations（2—4 条，不空话）；
- Sensitivity/Error Analysis（参数/残差/情景）；
- Conclusions/Future Work（明确回答题目）。

**不要**只写“模型很好、还需改进”两句。

## 7.5 图表与英文

- 图多、信息密度高：多面板、对比图、流程图、热力图、情景图。
- 图题是描述性句子，不是“Results”。
- 表多为关键结果表/参数表/对比表；大表放附录。
- 英文不要求 native；要求**清楚、术语一致、数字准确**。优秀论文也有语法小错，但结构清楚。
- 常见可读性做法：短句、主动语态、每段主题句、数字+单位、图前有“Figure N shows...”。

## 7.6 2022—2025 的题型信号

- 2022：A 图像/分类，B 物理/传热，C 气候/数据，D 相变/传热，E 核武器/预测。
- 2023：A 机器人/运动，B 物理/光学，C 新能源车/政策数据。
- 2024：A 水下图像增强，B 物理/优化，C 宠物产业/数据，D 量子/优化。
- 2025：A 人形机器人，B 辐射制冷，C 关税/贸易，D 机组组合/量子。

**信号**：

1. APMCM 题面越来越“美赛化”：开放、跨学科、给真实数据/背景。
2. 数据类题（C）稳定存在，竞争最激烈；工程/物理/运筹题对背景要求高。
3. 2026 仍可能 A—D 四题；不要押题，按“数据可得性 + 队伍背景 + 4 天可完成度”选。
4. 获奖论文的共同点不是“模型最新”，而是**问题回答完整、证据链闭合、英文可读、图表清楚**。

## 7.7 对 2026 的直接建议

1. Summary 350—450 词，每问 2—3 个数字；D1 开始写，D4 只润色。
2. 正文按问题驱动标题，不强行“Model I/II/III”；每问都有 analysis → model → result → validation → mini-conclusion。
3. 图 10—20 张，表 3—8 张；图题描述结论，表放关键数字；大表进附录。
4. Model Evaluation 单独一章，写优点/缺点/敏感性/结论，不要空话。
5. 英文以清楚为先；术语表 + 短句 + 数字单位；不要为了“高级”写长难句。
6. 正文 ≤25 页；不要拿“获奖论文 30+ 页”当借口；2026 规则优先。

## 7.8 章节标签的出现频率（16 篇，按全文关键词统计）

| 标签/结构 | 出现篇数 | 解读 |
|---|---:|---|
| Introduction | 16/16 | 必备 |
| 每问独立模型/求解章节 | 16/16 | 必备 |
| Advantages/Strengths | 14/16 | 几乎必备；不一定要叫这个名字 |
| Weaknesses/Limitations | 8/16 | 常用 Limitations/Weaknesses/Discussion |
| Sensitivity | 11/16 | 参数/情景敏感性很常见 |
| Model Evaluation | 8/16 | 有的用 Advantages and Limitations 替代 |
| Our Work | 6/16 | 常用路线图；没有也不致命 |
| Problem Analysis | 8/16 | 有的并入 Introduction 或每问开头 |
| Conclusions | 10/16 | 常与 Model Evaluation/Policy 合并 |
| Error Analysis | 3/16 | 不强制，但稳定性/敏感性更常见 |
| Future Work | 2/16 | 可选；有则加分 |
| Appendix | 14/16 | 代码/补充材料；官方要求全部源码 |
| References | 14/16 | 官方要求；个别论文可能把参考放在别处 |

**结论**：不要死抠标题名。评委看的是“每问有没有回答、有没有验证、有没有优缺点”，不是标题是否叫 Model Evaluation。

## 7.9 页数分配的获奖样本

| 论文 | 总页 | 正文章节分配（近似） |
|---|---:|---|
| 2025 D | 27 | p3 Restatement；p4 Analysis；p5 Symbols/Assumptions；p6—26 四个模型；p27 Advantages/Limitations |
| 2025 C | 27 | p3—5 Intro；p6—7 Data；p7—25 五个 Question；p26 Conclusion/Policy；p27 References |
| 2024 A | 50 | p3—5 Intro/Assumptions/Notation；p5—27 四个 Question；p26—27 Evaluation；p28 References；p29—50 Appendix |
| 2023 B | 23 | p3 Intro；p3—4 Restatement/Analysis；p4—7 Models；p7—19 Results；p19—22 Pros/Cons；p23 References |
| 2022 B | 30 | p3—5 Intro/Assumptions/Symbols；p6—22 Models；p22 Evaluation；p23 Optimization/Future；p24 References；p25—30 Appendix |

**规律**：

- Introduction + assumptions + notation 通常 **3—5 页**；不要写 8 页背景。
- 每问 **4—6 页**；问题多时每问 3—4 页，但每问必须有结果与验证。
- Model Evaluation/Conclusions **1—2 页**；不要只有两句话。
- References/Appendix 不计入 25 页；但正文不要把附录内容提前写一遍。

## 7.10 Summary 的“获奖动作”拆解

从 16 篇看，Summary 的有效结构是：

1. **1—2 句背景**：问题为什么重要，不要从百科定义开始。
2. **1 段总方法**：数据/模型族/验证方式，一句话说清。
3. **每问 1 段**：
   - 方法（模型名/算法/数据）；
   - 2—3 个关键数字；
   - 结果意味着什么。
4. **1—2 句结论 + 边界**：不能声称什么。
5. **Keywords 3—5 个**。

**数字密度**：中位 18.5 个；不要只有 2—3 个，也不要堆 50 个无解释数字。
**词数**：中位 387；目标 350—450，超 500 要压，低于 300 通常太薄。

## 7.11 图表与英文的获奖样本

- 图：中位 14 张，最多 34 张；很多论文图多于表。
- 表：中位 4 张，最多 10 张；有的论文几乎不用表，用图+文字。
- 图题是描述性句子（“Figure 7.8 Optimization: Revenue vs. Welfare Divergence”），不是“Results”。
- 图内常有多面板 (a)(b)(c)(d)，一图回答一个比较。
- 英文：优秀论文也有语法/拼写小错；但**术语一致、数字清楚、每段有主题句**。不要为了“地道”牺牲信息密度。
- 常见句式：`Figure N shows ...`、`Table N reports ...`、`Compared with ..., the proposed model ...`。

---

## 7.12 不要照抄的“获奖论文例外”

1. 有的论文正文超过 25 页（可能是旧规则/页眉计数/附录边界），2026 仍按官方 25 页。
2. 有的论文没有 Appendix 或 References 的完整形式；官方要求全部源码/引用，不能照抄缺口。
3. 有的论文用 `Abstract` 而不是 `Summary`；官方模板是 summary sheet，按模板。
4. 有的论文标题/章节很文学化（如 Open Letter）；没有对应写作能力时，不要模仿，先把问题回答完整。
5. 有的论文图非常多（30+），但每张都有信息；不要为了数量堆图。

## 7.13 按题型选章节组织（从获奖论文反推）

### 数据/政策类（C 题常见）

2025 C 的组织：

```text
Introduction
Assumptions and Notations
Data Preprocessing and Descriptive Analysis
Question 1: ...
Question 2: ...
Question 3: ...
Question 4: ...
Question 5: ...
Conclusion and Policy Recommendations
References
```

2023 C 更“叙事化”：章节标题直接是问题结论（`What Will the NEEVs Be...`、`An Open Letter...`）。
**可复用点**：

- 数据清洗单独一节，写清来源、单位、缺失、口径；
- 每问用“情景/反事实/机制”回答，不要只做描述统计；
- 结论章给政策建议，但要写边界（模型假设、外生冲击、数据限制）；
- 图表用时间序列+政策事件标注、份额/网络/情景对比。

### 工程/物理类（A/B 题常见）

2024 A / 2025 D 的组织：

```text
Introduction
Problem Analysis
Assumptions / Notations
Model 1 ... Model N（每问：分析→模型→求解→结果→验证）
Model Evaluation（Advantages / Limitations / Sensitivity）
References / Appendix
```

**可复用点**：

- 先写“问题分析”，再写“模型”；不要一上来堆公式；
- 每个模型有假设/变量/目标/约束/求解器；
- 结果图要能看出物理/工程意义；
- 模型评价必须有局限性，不要只写优点。

### 优化/算法类（D 题常见）

2025 D 的组织：

```text
Problem Restatement
Problem Analysis
Symbol Legend
Basic Assumptions
Classical MIP Model
Network/Security Extension
QUBO Conversion
Scale Reduction
Advantages and Limitations
```

**可复用点**：

- 按“经典模型 → 扩展 → 转换 → 规模缩减”递进；
- 每步都给结果/对比，不要只写推导；
- 最后必须有“经典 vs 量子/启发式”的对比与规模可行性；
- 复杂度/比特数/运行时间要写清。

### 页数紧张时的紧凑写法

2023 B（23 页）用：

```text
Introduction → Restatements/Analyses → Models → Solutions and Results → Pros and Cons → References
```

把“模型”和“结果”分开成两章，适合 3—4 问、每问模型相似的情况。
**不要**为了省页数把验证删掉；删背景、合并方法描述、移大表到附录。
