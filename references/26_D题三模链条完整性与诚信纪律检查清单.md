# 26. D 题三模链条完整性与诚信纪律检查清单（高奖冲刺专用）

> 用途：①每个问题（P1/P2/P3）交付时的**验收闸口**；②论文写作时的**结构自检**；③评委攻击前的**自我攻防演练**。
> 原则：高奖 = 无原则性问题（一票否决项为零） + 三模链条环环有证据 + 至少两个差异化反超点。本清单按此三层组织。
> 与 `references/25_D题量子优化优秀论文解剖.md`（写作章法）、`assets/apmcm_submission_checklist.md`（格式合规）互补：本文件管**方法论与诚信**，不管排版。

## 26.2 三模链条完整性检查（每问一张表，缺一不可）

### P1（代理模型：两阶段筛选+数值预测）

| 环节 | 必查项 | 合格标准 |
|---|---|---|
| **模型建立** | 问题形式化是否写清（输入/输出/目标事件 EF_{V<=2}@20）？特征工程物理依据是否逐条有出处？两阶段架构的文献依据（Talapatra/Mayr&Gagliardi）是否引用？ | 公式+特征表+引用三件套齐全 |
| | gap=0 处置是否有题内依据（V>=7.84 推导）而非纯工程决定？ | 推导链条在论文中可见 |
| **模型求解** | 训练是否有防泄漏协议（AB/元素/X 隔离）？拟合次数是否记账？超参是否固定菜单而非试到好为止？ | 嵌套 CV 结构图+次数账本 |
| | 8 条对照路线是否全部并列报告（含负结果）？ | 结果表无选择性缺失 |
| **模型检验** | 主验证+元素阻断+X 留出+目标区域留出四种协议是否分别报告？EF 统计是否带单侧超几何 p 值+正确分母？校准诊断（Brier/可靠性曲线）是否展示？ | 四协议结果表+统计检验节 |
| | 声称边界是否写清（近正例富集 ≠ 零点识别能力）？ | 边界声明在结果节连体出现 |

### P2（NO2 池 QUBO 选择）

| 环节 | 必查项 | 合格标准 |
|---|---|---|
| **模型建立** | 104-bit 编码数学推导是否完整（one-hot 约束→罚项→QUBO 矩阵）？λ 定标是否有解析推导（减最小值重参数化+裕量）而非"足够大"一句带过？ | 转化章法四步+λ 推导——**这是反超 2025D 的差异化点** |
| **模型求解** | SA/CIM/暴力三轨是否同表对照？求解参数是否披露？ | 对照表含 Gap% 列 |
| **模型检验** | 可行域枚举审计是否执行（2,704 合法态全枚举）？约束逐条验证是否织进结果（验证列内嵌）？原表 regret 是否报告？ | 枚举审计器输出+验证列 |
| | 真机结果是否有控制台证据+重复次数+修复前后分离报告？ | 证据链完整 |

### P3（联合选择+精度适配）

| 环节 | 必查项 | 合格标准 |
|---|---|---|
| **模型建立** | X 族范围（三族 208-bit / 七族 416-bit）是否与题面核实一致？编码三路（分解/复合/HOBO）是否同表对照？ | **口径核实记录留档——写错即硬伤** |
| **模型求解** | 成本账本是否一行一完整流水线（位数/耦合/时间/调用数）？ | 账本结构按第四轮审定版 §3.3 |
| **模型检验** | 8-bit 精度分析是否区分表示失败 vs 搜索失败？三层误差拆解（代理/量化/求解）是否各自量化？三层基准协议前两层是否先完成？ | 精度三联图+误差账本表 |
| | 价值声明是否用"保真度与成本"框架而非"量子优势"？ | 模板句逐字检查 |

## 26.3 高奖差异化反超点清单（对照 2025D 获奖基线）

2025D 优秀论文的实际水准（已解剖确认）：
- λ 罚系数一句话带过 → **我们给解析推导+三保证分层声明**（反超点 1）
- 评估章仅 2 优点+1 局限段、无敏感性分析 → **我们给四协议验证+三层误差拆解+敏感性分析**（反超点 2）
- 参考文献仅约 5 条且含中文期刊与 arXiv → **我们给 20+ 条近五年高质量文献（npj/Nature 子刊/ Commun. Mater.）**（反超点 3）
- 无统计显著性概念 → **我们给超几何检验+冻结哈希+分母诚实**（反超点 4）
- 验证织进结果但无系统审计 → **我们给可行域枚举审计器（2025D 的 UC 问题无法枚举，我们的 2,704/8,112 恰好可以——这是本题独有的验证奢侈品）**（反超点 5）
- 精度适配完全没做（2025D 只字未提 8-bit）→ **我们的精度-位宽实证+PrecisionReducer 对照是独家内容**（反超点 6）

**写作纪律：反超点必须落在证据上（表/图/推导），不能在文中自夸"比往年工作更严谨"。**

## 26.4 评委攻防演练问题单（交付前自问自答）

1. 你的池可枚举，为什么需要量子？——答：枚举是精确参照，QUBO 实验评估形式保真度/精度鲁棒性/实现成本（模板句见第四轮审定版 §3.4）。
2. 19 个正例全在 holdout，你的模型选择真的没用它们吗？——答：开发集用 V<=2 近正例事件选模，holdout 仅冻结后一次性评估，哈希+时间戳为证，历史暴露已披露。
3. EF=19.49x 和 EF=99.6x 哪个是真的？——答：分母匹配实际筛选池，两个都报并解释差异。
4. 命中 2/20 也可能是运气？——答：单侧超几何 p=0.00449（3,703 池），同时披露区间宽度与可迁移性限制。
5. 8-bit 把小系数抹零了，你的量子结果还有意义吗？——答：表示失败与搜索失败分离测量；完整哈密顿量（含局部场+参考自旋）的可行域枚举审计显示 XX（用实际数据回答）。
6. 门控概率乘回归值是命中概率吗？——答：不是；我们用概率链式乘积 P(G=1)·P(V<=2|G=1)，第二项是真正的条件事件概率且经折外校准。
7. 你的λ怎么定的？——答：减最小值重参数化+解析下界+10% 裕量，三种保证分层声明（推导在论文 §X）。
