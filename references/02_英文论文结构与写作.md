# 02 英文论文结构与写作

> APMCM 的英语不是“翻译腔能过”的英语。评审要在 25 页内看懂：问题是什么、假设是否合理、模型为什么有效、结果是否稳定、结论是什么。
> 本文给结构、句式、常见错误和 summary 模板。

---

## 2.1 用“问题链”组织，不用“方法链”堆砌

每一问都按：

```text
Question → Difficulty → Assumption → Model → Solution → Result → Validation → Answer
```

不要写成：

```text
We use A. Then we use B. Then we use C. (没有回答题目)
```

评审第 3、4 条看的是“建模思路/模型是否有效”，不是“用了多少模型”。

---

## 2.2 全文结构

```text
p1 Summary
p2 Contents
1 Introduction
  1.1 Background
  1.2 Problem Restatement
  1.3 Our Work
2 Assumptions and Notations
  2.1 General Assumptions
  2.2 Notation
3 Data / Problem Analysis
4 Question 1: ...
  4.1 Problem Analysis
  4.2 Model
  4.3 Solution
  4.4 Results
  4.5 Validation / Sensitivity
  4.6 Summary
5 Question 2: ...
...
N Model Evaluation
  N.1 Strengths
  N.2 Weaknesses
  N.3 Sensitivity / Robustness
  N.4 Conclusions
References
Appendix (software + all source code)
```

## 2.3 Summary（第一页）

### 结构

```text
Problem Chosen: C
Team Number: apmcm26XXXXX

Summary

[1–2 sentences: background and why it matters.]
[1 paragraph: overall approach, data, validation.]

For Problem 1, we [method]. The [metric] is [value], compared with [baseline].
For Problem 2, we [method]. [Key result with number.]
For Problem 3, we [method]. [Key result with number.]
For Problem 4, we [method]. [Key result with number.]

[1–2 sentences: conclusion/meaning; explicit boundary.]

Keywords: keyword1; keyword2; keyword3; keyword4
```

### 规则

- 一页；不跨页；无公式/图/表/参考文献角标。
- 每问至少 1 个数字；数字与正文/结果文件一致。
- 用过去时写“做了什么”，现在时写“结论/意义”。
- 不写 “very good / obvious / significant” 这种无证据评价。
- 关键词 3—5 个，覆盖对象+方法+应用。

### 常见错误

| 错误 | 改法 |
|---|---|
| 只复述题目 | 加方法 + 每问数字 |
| 每问没有数字 | 从 `key_numbers.csv` 取 |
| Summary 跨页 | 压句/删背景；不要缩字号 |
| 关键词 8 个 | 3—5 个 |
| 出现中文标点 | 全文替换为英文标点 |

## 2.4 正文段落写法

### 问题分析

```text
The problem asks us to [task]. The main difficulty is [difficulty], because [reason].
We therefore [approach], which allows us to [capability]. The output is [output].
```

### 模型

```text
Let x_i denote ...; y_i denote ...
The objective is ... subject to ...
The model is appropriate because [reason 1] and [reason 2].
```

### 结果

```text
Table 4 reports ... The proposed model achieves [value], compared with [baseline] ([value]).
The improvement is [absolute/relative], while [side effect] remains [value].
```

### 验证

```text
We check ... The maximum residual is ... (machine precision).
We perturb ... by ±10%; the objective changes by ...%, so the conclusion is stable in this neighborhood.
As a negative control, we permute ...; the metric drops to ..., close to the null level.
This does not prove ..., but it supports ...
```

### 边界

```text
The result holds for [scope]. It is not an estimate of [out-of-scope quantity].
We do not claim [causality/generalization/real-world safety].
```

## 2.5 英文常见问题

| 问题 | 例子 | 改法 |
|---|---|---|
| 长句 | 50+ words, multiple clauses | 拆成 2—3 句，一句一个主张 |
| 时态混乱 | “We use... The result showed...” | 方法/实验过去时；结论现在时 |
| 缺冠词 | “We build model” | “We build a model” |
| 单复数 | “The result are” | “The results are” |
| 中文标点 | “，。；：（）” | 英文 `, . ; : ( )` |
| 术语漂移 | model/framework/approach 混用 | 建 `terminology.md`，全文统一 |
| 过度形容词 | “very significant improvement” | 给数值 + 比较 |
| 图内中文 | 中文坐标轴/图例 | 重绘英文；不能贴中文截图 |

---

## 2.6 术语与数字一致性

- 建 `terminology.md`：每个概念只留一个英文写法。
- 建 `key_numbers.csv`：summary/正文/表/图共用同一份数字。
- 单位统一：`kWh`, `%`, `USD`, `mm`, `s`；数字与单位之间留空格（按期刊/模板习惯统一）。
- 百分比、千分位、日期格式全文一致。

---

## 2.7 英文 QA 顺序

1. 术语统一；
2. 每段主题句；
3. 时态；
4. 冠词/单复数；
5. 标点/全角；
6. 数字/单位；
7. 图题/表题；
8. 最后再润色“高级表达”，不要反过来。
