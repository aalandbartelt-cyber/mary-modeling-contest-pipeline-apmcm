# 18 C 题（数据类）优秀论文逐页解剖

> 样本：2022C（66p）、2023C（27p）、2024C（37p）、2025C（27p 正文，原书 55p）。
> 方法：逐页统计词数/图/表/节标题 + 代表页版面检查。聚合指标见 `07` 与 `assets/award_paper_metrics.csv`；本文件回答的是"每一页具体长什么样"。
> 建模叙事/公式规范/可读性句式的实证拆解见 `20_建模叙事公式与可读性规范.md`。

## 18.1 逐页地图（四篇对照）

### 2025C（27p 正文，最推荐的范本）

```text
p1   Summary（品牌化框架 SMDEF，见 18.3）
p2   Contents
p3   Introduction（~400 词）
p4   框架图整页上半 + 三层架构说明（Figure 1.1 workflow 图 + 3 层文字）
p5   Assumptions & Notations（表 1）
p6   Data Preprocessing：Outlier / Missing / Harmonization 三段（~360 词纯文字）
p7–13  Q1 大豆：机制假设→参数校准(σ=5.0)→仿真结果表→对比图→编号发现→敏感性
p14–16 Q2 汽车：3 面板时序图 + 3 情景堆叠图 → Gains/Losses/Neutral → Conclusion for Q2
p17–20 Q3 芯片：Innovation Loop 机制图 → 情景 A/B → 国产制造与全球贸易影响
p21–23 Q4 收入：Baseline Asymmetry / Efficiency Decay / Trade Diversion 三组发现
p24–26 Q5 综合：Debt Spiral / Crypto Hedge / USD Paradox（相关性 +0.88/+0.65/+0.55）
p27  References / Appendix 起
```

### 2024C（37p，"教科书式"路线也获奖）

```text
p1 Summary（~400 词）    p2–3 Contents（两页目录）
p4 Introduction + 逐问 Restatement
p5–6 专设"Analysis of Question 1–4"两页（先分析后模型）
p7–8  Q1 Data analysis（图+表）
p9–11 发展因子分析（相关性柱状图组）
p12–15 预测：Time series → Random Forest → Hybrid（每法一节，方法定义→公式→图）
p16–20 Q2 海外对比：Data Collection → 特征构建/筛选 → 建模求解
p21–26 Q3 宠物食品：Data → Processing → 建模求解 → 结果图组
p27–29 Q4 博弈模型：假设与变量 → 静态博弈 → 动态博弈 → 求解结果
p30 Advantages（证据化）   p31 Disadvantages
p32–37 References + Appendix（约 6 页）
```

### 2023C（27p，叙事化路线）

```text
p1 Summary（~300 词，偏短）   p2–3 Contents
p4–27 连续叙事体：罗马数字章节，章名即结论
  （"VII. Resistance to China's NEEVs and the Impact"、"An Open Letter..."）
每页 110–300 词，图较朴素（3D 饼图、柱状图），靠叙事逻辑和政策分析获奖
无独立 Appendix（本副本 27p，原书 31p）
```

### 2022C（66p，图海+大附录路线）

```text
p1 Summary（~512 词，偏长）   p2 Contents
p3–4 Introduction（含 1.3.x 逐问重述）
p5–6 Notations + Data Description + Data Cleaning（缺失/标准化两段）
p7–13  Q1：Verification→预测模型→Conclusions→Precision（图密，p7 仅 73 词几乎全图）
p14–22 Q2：时空关系→自然灾害关系→主因→对策
p23   Sensitivity Analysis
p23–24 Model Evaluation（多元线性→随机森林→GA-BP 三模型对比）
p24–25 Conclusions + "9. Article"（1 页非技术文章：发现重述→A–F 条建议）
p26–28 References 等
p29–66 附录：约 38 页代码（每页仅几个英文词 = 代码清单页）
```

## 18.2 每页版式配方（从词数/图表分布反推）

| 页型 | 词数 | 构成 | 例子 |
|---|---:|---|---|
| 纯文字分析页 | 300–420 | 2–4 段，可含 1 个公式 | 2025C p6 预处理、2024C p5 问题分析 |
| 标准结果页 | 150–260 | 1 表或 1–2 图 + 解读段 + 编号发现 | 2025C p9（表+图+3 条发现） |
| 图组页 | 100–180 | 2–4 张图（多面板/对比）+ 1–2 段 | 2025C p14–16、2024C p12 |
| 近全图页 | <100 | 流程图/结构图占半页以上 | 2022C p7（73 词 3 图） |
| Summary | 300–510 | 见 18.3 | 四篇 p1 |
| Contents | ~130 | 全自动目录 | 四篇 p2 |
| 代码附录页 | <10 | 整页代码清单 | 2022C p29–66 |

**可执行规则**：

- 结果页 = **1 个证据件（表或图）+ 解读段 + 编号发现句**；只放图不解读的页在四篇里都极少且紧跟解读页。
- 每问 4–7 页（2025C 五问 ≈ 每问 3 页、2024C 四问 ≈ 每问 6 页）；前置"问题分析/数据说明"1–3 页。
- Intro+假设+符号 ≤5 页；结论/评价 1–2 页；代码附录页数不设限（2022C 38 页代码）。

## 18.3 2025C 的"品牌化"手法（最值得抄的一页纸）

Summary 与全文的共同手法：

1. **命名总框架**：`Systemic Multi-Dimensional Evaluation Framework (SMDEF)`——给整套方法起一个名字+缩写，p4 立刻配三层架构图（Data Input → 3 条 Modeling Track → Policy Output + 反馈环）。
2. **每个模型命名**：Constrained Armington Model、Dynamic Stackelberg Game、Bi-level Policy Simulation、Crisis-Aware Forecasting、Supply-Side Shock Model——评委复述时有词可用。
3. **每个发现起记忆点**：Export Collapse、Capacity Capped、Spillover Dividend、Tariff Tipping Point、Forced Localization、Boomerang Effect、Stagflationary Trap、Debt Spiral、USD Paradox。
4. **发现写成编号句**：`1. U.S. Export Collapse: A 25% retaliatory tariff induces ... sharp 57.1% decline`——名字 + 数字 + 机制，一句一件。
5. **结果表带解读列**：Table 3 最后一列 `Impact Analysis` 直接写机制（"Market Collapse: Price uncompetitiveness drives share decline"）。
6. **图分组回答子问题**：Figure 5.5 三面板（就业/税收/车价带政策阴影带），Figure 5.6 三情景堆叠图。
7. **每问结尾固定小节** `Conclusion for Question N`：3 条编号 takeaway。
8. **参数在使用处给值**：`σ = 5.0, Cmax = 1.1×Baseline, τUS = 0.25` 直接写进结果段首句，出处（GTAP 10）随行标注。
9. **Summary 分两层叙事**：Micro-Level Impacts / Macro-Level Insights / Synthesis 三个小标题，bullet 内嵌 `(Q1)–(Q5)` 标签。
10. **敢下政策结论**："shifting from distortive border taxes to fiscal prudence and targeted domestic industrial subsidies"。

**注意**：品牌化是 2025C 的加分项不是必需项——2023C/2024C 没有命名框架也获奖；但"编号发现句 + 每问小结 + 表带解读"是三篇共有的，优先学这三个。

## 18.4 四篇的风格光谱：获奖不止一条路

| | 2022C | 2023C | 2024C | 2025C |
|---|---|---|---|---|
| 总页/正文 | 66 / ~25 | 27 / ~25 | 37 / ~30 | 55 / 27 |
| 章节命名 | 功能型（5.1 Models...） | 结论型（章名即答案） | 功能型 + 专设问题分析章 | 问题驱动 + 品牌化 |
| 图风格 | 量大、朴素、含截图 | 最朴素（3D 饼图） | Excel 风柱状图 | 精致多面板、注释图 |
| 文字密度 | 不均（图页<100 词） | 稀疏（110–300 词） | 中等（200–400 词） | 中高且结构化 |
| 方法呈现 | 验证→模型→精度 | 指标先论证再使用 | 教科书式"定义→公式→图" | 参数来源→机制→发现 |
| 显著加分件 | 3 模型对比评价章 + 非技术 Article | 政策叙事 + Open Letter | 混合预测 + 博弈模型收尾 | 命名框架 + 编号发现 |
| 附录 | ~38 页代码 | 无（副本） | ~6 页 | ~28 页 |

**共性（四篇全有）**：
- 每问结果有数字、有解读、有小结；
- 数据段单独写来源/清洗/口径；
- 摘要每问有数字；
- 结论落到政策/建议层；
- 页眉 `Team # xxx / Page x of y`。

**允许"丑"的地方**：图可以是 Excel 默认配色、3D 饼图（2023C/2024C 实证）；图题用 Picture 也行（2022C）。不允许的是：图无解读、问无小结、摘要无数字。

## 18.5 跨 16 篇的深扫补充（公式/小结件/图题/分析章）

**公式密度按题型分层**（编号公式计数，启发式）：

| 档 | 篇 | eq_count |
|---|---|---|
| 数据档（9–34） | 2022C=9、2023C=9、2025C=10、2024C=34 | **数据题不靠堆公式** |
| 物理/优化档（27–56） | 2025D=56、2024B=45、2025B=43、2022A=32、2025A=27、2022D=27 | 推导链是得分主体 |

**每问"小结件"功能普遍、名字各异**：2025C 用 `Conclusion for Question N`（显式小节）；2022A 用 `5.x.5 Short summary`；2023C 用"章名即结论"；2024C 靠末章 Advantages/Disadvantages 收束。规则：**每问必须有可定位的小结件，叫什么不重要**。

**图题是描述性短语不是结论句**：实测图题 6–10 词名词短语（`Comparative Forecast of Export Volumes Before and After Tariff Shock`、`U.S. Manufacturing Employment, Tariff Revenue, and Vehicle Prices`）。**结论写在正文编号发现句里，不是图题里**——之前"图题写结论"修正为"图题写清内容，结论放发现句"。

**"先问题分析后建模"专设章反复出现**：2024C 用 p5–6 两页 `Analysis of Question 1–4`，2022A 用 `2 Problem analysis`（2.1/2.2/2.3 逐问）。数据题建议照做：问题分析 1–2 页，每问一段"题目要什么→我们的思路→预期产出"。

**A 题图像数据集题与 C 题同构**：2023A（苹果识别）与 2022A（连铸图像）都是"同一数据集五问递进"，页面配方与 C 题一致——数据队伍在 A 位有备选。

**截断副本警告**：本地 16 篇里 5 篇页眉总页数 > 实际页数（2023B 44v23、2023C 31v27、2025A 46v29、2025B 51v36、2025C 55v27），缺的主要是附录/参考页。附录页数、总页数指标一律按下限解读；规程见 `19`。

## 18.6 非技术 Article/Letter 页的写法（2022C "9. Article" 实例）

一页内完成：

```text
第 1 段：用大白话重述问题与动机（"The warming process ... is beyond the laws of nature"）
第 2 段：重述关键发现，数字保留但不带公式
  （"in 2050 ... 19.96 degrees" "the global average temperature will reach 20 degrees in 2055"）
第 3 段："Therefore, our team makes the following recommendations:"
A–F 条建议，每条 1–3 句，动词开头（Introduce/Increase/Strengthen/Formulate/Protection/Reform）
```

无公式、无图号、无模型名堆砌（模型名出现也用普通词："nonlinear prediction model based on random forest algorithm"）。

## 18.7 附录形态

- 代码附录 = 整页代码清单，页词数 <10；38 页代码也没人嫌长（2022C）。
- 附录前常有 1–2 页支撑材料/补充表（2022C p26–28、2024C p32–34）。
- 支撑件命名：附件清单、补充表放代码前；代码按问或按文件分节标题。

## 18.8 对 2026 数据题的页面级清单

- [ ] p1 Summary：每问数字 + 1 个总框架名（如有）+ 敢下结论；350–450 词；
- [ ] p2 Contents；Intro+假设+符号 ≤5 页；
- [ ] 数据节单列：来源/口径/清洗/锚点核对（2025C 用整页写预处理）；
- [ ] 每个结果页：1 证据件 + 解读段 + ≥1 条编号发现句（名字+数字+机制）；
- [ ] 至少 1 张框架/流程图（架构图或问题链图）放在 Intro 末或首个模型节开头；
- [ ] 关键结果表带解读列或紧随解读段；
- [ ] 图分组：同主题 2–3 面板一图，图题写清内容（6–10 词短语），结论放正文发现句；
- [ ] 每问结尾 `Conclusion for Question N`（3 条编号句）；
- [ ] 敏感性/稳健性放在问内小节（5.3.1 式），不全堆到末章；
- [ ] 若题面要 Article/Letter：1 页、大白话、发现重述 + 字母编号建议，无公式；
- [ ] 结论章敢给政策判断 + 边界；代码附录不限页数但要有分节标题。

## 18.10 2025A/B/D 逐页地图（紧凑版，非 C 题参考）

**2025A 机器人（29p 截断本，页眉 of 46）**：罗马数字章制；前置 p3–5（Intro/Our works/假设）；**按问分页不均**：Q1 p6–9(4p)、Q2 p10–12(3p)、Q3 p13–18(6p)、Q4 p19–25(7p)——**最后的综合优化问拿最多页**（整合前三问）；评价 p26、文献 p27+。图集中在结果页（p18 一页 6 图引用）。

**2025B 材料（36p，页眉 of 51）**：前置偏长 p4–8（Intro/分析/假设/符号**各占独立章**）；Q1 p9–14、Q2 p15–22、Q3 p23–29、Q4 p30–34；评价 p34。图密页与纯文字页交替；**物理题每问 5–8 页**。

**2025D 量子优化（27p 完整）**：Restatement+分析 p3–4、符号+假设合页 p5——**前置最紧（3 页）**；四问**均匀分配各 5–6 页**（Q1 p6–10 / Q2 p11–16 / Q3 p17–21 / Q4 p22–26）；评价 p27。**优化题结果以表为主**（每页 T2–4 表、图仅 11 张）——与 C 题图驱动形成对照。

**跨题型页数配方总结**：
- 前置预算：紧凑 3 页（D/SW26 式）到宽松 5 页（B 式）都获奖，但**紧凑是趋势**；
- 每问页数：工程/优化题均匀（4–6p/问），**集成型末问加重**（A 的 Q4=7p）；
- 证据载体：数据/政策题图驱动（1 图/页），优化/物理题表驱动（2–4 表/页、图点缀）。
