# 30. 用户数维杯论文（CSWBMCM2619167）视觉风格解剖

> 来源：用户本人 2026 第十二届数维杯交付论文（85 页 PDF，正文 23 页 + 约 60 页附录证据）。用户自评"图表很不错"——本文是其视觉语言的逆向工程，**APMCM D 题出图的用户审美基准**。2026-11 蒸馏。

## 30.1 实测色板（程序化提取，可直接抄 hex）

**基调：钢蓝家族 + 琥珀点缀的低饱和学术色系**——与用户否决"灰尘暗调"不矛盾：这套色系明度中等偏上、色相清晰，"灰"的是饱和度不是明度。

| 角色 | 实测 hex | 用途 |
|---|---|---|
| 主色-深钢蓝 | `#46657a` / `#4a697e` | 主线/主系列、首系列 |
| 主色-中钢蓝 | `#59768a` / `#648093` | 次系列、面板填充 |
| 主色-浅钢蓝 | `#7891a2` / `#9db1bd` | 第三系列、背景填充带 |
| 点缀-琥珀金 | `#dc9848`（浅化 `#e7bf8e`） | 强调系列、对比列、最优点 |
| 辅助-灰绿/青 | 桑基图中 muted teal-green | 第三语义 |
| 辅助-灰粉 | 桑基图中 muted pink | 第四语义（少量） |
| 中性-浅灰蓝 | `#ced8df` | 参考线、未用区间、背景层 |
| **发散色图** | 蓝 `#587aa4` → 白 → 琥珀 `#dc9848` | **带符号量专用**（负蓝正琥珀，零为白） |

关键洞察：**发散色图不用红绿用蓝-琥珀**——色觉安全天然达标，且与整篇色系同源。D 题的 regret/改进量/符号变化全部应继承这个发散色图。

## 30.2 九条视觉模式（比色板更重要的东西）

1. **图型严丝合缝匹配数据结构，绝不用默认柱线图**：时间分解→**桑基图（ribbon flow）**；应力矩阵→**环形热图（内外双环编码两个策略、六扇区编码离散应力）**；路由→轴测场景图。评委看到的是"这个图型就是为这个数据生的"。
2. **正文先教读法，图后出现**："Figure 9A maps signed changes to color: the inner ring is service priority, the outer capacity balance. The six sectors identify discrete stresses; sector size carries no value."——**复杂图必配"阅读指南句"在正文先出现**，甚至明说"哪个维度不携带信息"。
3. **数值直接焊在图元素上**：桑基带子上印 76.47s/18.38s、环形扇区印 −2.78/−4.29、柱端印 0.181 与 Δpp——评委不翻正文就能读完图。
4. **多面板同构对比**：A=Validation / B=Test-pool 完全相同的结构并排，差异一眼可见；面板字母在左上外侧。
5. **图内灰色小字注解**："Ribbon thickness = mean time; each policy contributes 108.33 s"——图区底部浅灰小字交代编码规则，不占正文。
6. **caption 极简话题式**："Figure 9. Forecast stress and computation budgets"——粗体编号+一句话主题，**解读全在正文**（与 playbook 的结论句风格不同，但本篇证明：只要正文解读够密，短 caption 完全成立）。
7. **booktabs 表格**：粗顶线-细中线-粗底线、零竖线、数字右对齐、表题"Table 3. Service and resource outcomes by source pool"同上格式。
8. **版面密度高但透气**：表+文+大图自然流动，单页信息量约为普通论文 1.5 倍，无拥挤感——靠的是图内白空间和统一色系的秩序感。
9. **发散色图带水平 colorbar 在图下方**，标注"On-time change (pp); color encodes value"——色条必配文字说明编码含义。

## 30.3 结构级洞察

- **正文 23 页（Page X of 23 页眉）+ 附录 B.x 编号体系约 60 页**：正文每个论断都有"Appendix Figure B.22/Table B.34"指针——**正文是冰山尖，附录是证据仓库**。评委抽查任何一个数字都有完整备份。D 题论文应复制这个结构：正文 25 页内只放最强证据，诊断/稳健性全部附录化但正文带指针。
- 用户论文的验证叙事密度极高（"Independent ledger reconstruction checks 36,555 validation actions...reproducing 69,300 common metric values across 6300 trials"）——**用具体大数字陈述验证规模**，与我们的 914 次拟合账本/5000 次 bootstrap 完全同构，这种句子评委爱看。

## 30.4 向 D 题出图的移植映射（直接执行）

## 30.5 与用户色板裁决的关系

用户否决"灰暗沉"方向、接受"浅蓝浅黄浅绿"——本篇实测色板恰好是这个区间的成熟样板：**钢蓝=浅蓝压一档饱和、琥珀=浅黄暖化、灰绿=浅绿灰化**。给 Codex 的色板 v2 应以 30.1 的 hex 为 A 套基准线，而非凭空新造。
