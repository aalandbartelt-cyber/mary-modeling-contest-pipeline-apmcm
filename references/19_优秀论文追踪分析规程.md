# 19 优秀论文追踪分析规程（长期目标）

> 定位：把"分析获奖论文"做成可重复执行的年度管线。每年官方放出新一届优秀论文（约 12 月—次年 1 月）、或拿到更完整的论文副本时，按本规程走一遍，把新样本沉淀回 skill。
> 基线：2022—2025 四届 16 篇已完成首轮（聚合指标 `07`、C 题逐页解剖 `18`、D 题量子优化解剖 `25`、指标 `assets/award_paper_metrics.csv`）。

---

## 19.1 三步流程

### 第一步：批量扫描（10 分钟）

```bash
python scripts/analyze_award_papers.py --input <论文目录或zip> --out metrics.csv
```

- 先看 `hdr_pages` 列：**页眉 `Page x of y` 的 y > PDF 实际页数说明本地副本被截断**（基线里 5/16 截断：2023B/C、2025A/B/C，缺的多是附录/参考文献页）。截断本的附录/页数指标是下限，不要据此刻意模仿。
- 与 `assets/award_paper_metrics.csv` 旧基线对比：summary 词数、图表数、eq_count、med_body_words 是否漂移。

### 第二步：数据题逐页解剖（核心工作）

对当届数据类获奖论文（按规律通常是 C 题）做逐页地图：

```python
import fitz, re
d = fitz.open(path)
for i, pg in enumerate(d):
    t = pg.get_text()
    w = len(re.findall(r'[A-Za-z]{2,}', t))
    heads = [l.strip()[:60] for l in t.split('\n')
             if re.match(r'^\d+(\.\d+)*\.?\s+[A-Z]', l.strip())][:3]
    print(f'p{i+1:>2} w={w:>4} | ' + ' ; '.join(heads))
```

再渲染 4–6 个代表页成 PNG 人工看版面：summary 页、框架图页、一个标准结果页、一个图组页、结论/建议页、（如有）非技术 Article 页。

### 第三步：回写 skill

| 新发现 | 写到哪里 |
|---|---|
| 聚合指标漂移（词数/图数/页数） | 更新 `07` 的量化画像与 `assets/award_paper_metrics.csv` |
| 数据题逐页地图/新手法 | 追加到 `18` 的对应对照表 |
| 新章节形态/写法 | `07` 骨架或 `09` 写作规范 |
| 新的评审扣分点 | `SKILL.md` 常见错误表 |
| 新工具/数据源套路 | `16` 数据题实战 |
| 新图型/配色/注释手法 | `assets/apmcm_figure_playbook.md` + `18.9` 分布表 |

## 19.2 每个新样本必答的固定问题

1. **骨架**：章节怎么分？问题驱动还是模型驱动？有无专设"问题分析/数据说明"章？
2. **页面配方**：结果页是"证据件+解读+发现句"吗？图组页/全图页/纯文字页的词数落点？
3. **小结件**：每问小结叫什么（Conclusion for Question N / Short summary / 章名即结论 / 只有末章评价）？
4. **公式密度**：eq_count 属于数据档（9–34）还是物理档（27–56）？数据题不堆公式是已验证规律。
4b. **建模叙事**：模型节首是否有命名句？参数是否有"值+出处+论证"校准块？假设是否分全文级/模型级两层？公式有无 underbrace/where 白话？（规范见 `20`）
5. **图题**：描述性短语（6–10 词）还是结论句？
5b. **图表图谱**：图型分布（时序/柱/饼/面板/仪表盘/地图/流程图）？配色语义（实测/预测/政策/正负）？注释手法（事件线/最优点/图内标签/数值标签）？有无新图型值得写进 `assets/apmcm_figure_playbook.md`？
6. **摘要**：词数、每问数字数、有无命名框架/品牌化手法？
7. **附录**：代码页数、是否有数据说明/补充表、本地副本是否完整？
8. **冲突**：有没有做法推翻 skill 里既有建议？有就先改 skill，并记一条"为什么"。

## 19.3 已验证的跨年稳定结论（不要轻易推翻）

- 每问必须有"小结件"——名字不限，功能必须有；
- 结果必须有"名字+数字+机制"的可复述发现（形式不限：编号句/解读列/小节末段）；
- 摘要每问 2–3 个数字，350–450 词；
- 数据题 eq_count 低不扣分（9–34 vs 物理题 27–56），不堆公式；
- 图题是短描述性短语，不是结论句；结论放正文；
- 获奖路径多样（品牌化/教科书式/叙事化/图海），共性是"问答全+证据闭合"。

## 19.4 已知坑

- **截断副本**：本地 PDF 可能只是正文，附录缺页；用 hdr_pages 检测，指标按下限解读；
- **指标是启发式**：eq_count/代码页/小结件计数都是正则近似，跨年比趋势不比绝对值；
- **别抄题**：分析的是"获奖长什么样"，不是预测 2026 考什么；模型/结论不可迁移，版式/叙事手法可迁移。
