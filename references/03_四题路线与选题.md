**2026 选题提示**：

- A 是“CV + 评估 + 调度 + 建议信”的复合题，工作量最大但每问都有明确产出；有分割/遥感经验优先。
- B 是典型工业时序题，难点在**时滞随流量变化**与 10 炉次泛化；没有信号处理经验慎选。
- C 数据最全（含作者 R 代码与补充材料），但问题偏生态统计，写作要求高；适合统计/生物背景。
- D 是 QUBO/Kaiwu 路线，正样本率 0.1%，代理模型 + 量子退火是主线；与 2024/2025 D 同族，有积累的队优势明显。
- 2026 没有 E 题；四题任选一，题号与论文内容必须一致。

**规律**：

- **字母规律在 2026 被打破**：2022—2025 是 C=数据/产业政策、B=物理设计优化、A=图像或工程、D/E=硬核优化/前沿；但 2026 的 B 变成工业时序融合、C 变成生物声学，只有 A（图像）与 D（量子/Kaiwu）保持。**不要只按字母押题型，开赛先读四题题面**。
- C 题选的人最多（历史规律）；2026 C 数据最全但写作要求高，做完容易、出彩难。
- B/D 竞争小，但需要硬背景；不要只因“人少”选。
- **题量 3—5 不固定**：2022 五题、2023 仅三题、2024—25 四题；以当届为准。
- **出题紧跟当年时事**（2025 用 4 月对等关税、宇树机器人）→ 中文解读/公众号分析会很多，赛期检索中文资料是有效战术；代价是同质化更重，要靠数据深度与机制差异化。
- **附件是原始官方导出，不是干净数据**：口径核对、清洗、补外部数据是默认工作量；考察的是“数据+模型+结论”完整链条，没有唯一正确答案。
- **专业题可能指定产业方工具**：D 题连续两年指定同一厂商 Kaiwu 量子 SDK——前沿题带厂商推广性质是稳定模式，不是偶然；把现场学习成本算进选题决策。
- 难度介于国赛与美赛之间：题面美赛式开放，分问国赛式递进——每问有明确中间产出，好上手但别低估工作量。
- **最后一问常是非技术交付**：写信给公司/联合国/市民或一页非技术文章（2022 C/D/E、2023 C）——按非技术读者写，别堆公式，这是 APMCM 签名式设计。
- **可能给出显式分值**（2024 D 标注 20/40/40）：按分值分配工作量，高分值题优先。
- **数据题明说 “collect your own data”**：外部数据收集是预期动作，不是擦边球；题面给了数据字典就按字典引字段。
- 图像数据集可能走国内网盘外链下发（2023 A 微云），开赛前确认能下载。

## 3.2 A 题方法菜单：图像 CV / 工程优化

> 以下按字母给可迁移方法菜单，不代表 2026 题目；2026 实际题面见 3.1.1。

A 位 2022—24 连续三年是图像题（连铸序列图、苹果识别、水下增强），2025 才换机器人运动学。队伍有 CV 或控制/工程背景都先读 A 题。图像题的典型结构是五问同数据集递进：统计特征 → 定位/计数 → 状态估计 → 物理量估计 → 识别建模。

机器人/运动题典型链路：

1. 坐标变换/正运动学（送分）；
2. 步态/速度规划 + 关节角变化率；
3. 多关节协同 + 平衡约束（重心投影/支撑面）；
4. 能耗 = 力矩×角速度，电池容量；优化方案对比。

**得分点**：假设合理、运动学自洽、曲线/动画、能耗对比。
**坑**：直接上多体动力学导致做不完；忽略平衡约束；单位/角度制混用。

## 3.3 B 题：物理/光学/热辐射

典型链路：

1. TMM/菲涅尔计算发射率/吸收率随波长；
2. 热平衡：太阳辐射 + 大气下行辐射 − 8—13 μm 窗口辐射 − 对流；
3. 多层膜材料/厚度优化（GA/PSO/SA）；
4. 工程可行性/成本。

**得分点**：物理公式正确、材料参数来源、优化前后对比、工程边界。
**坑**：把发射率当常数；忽略大气窗口；优化目标/约束写不清。

## 3.4 C 题：数据/经济/政策

典型链路：

1. 数据清洗：编码/国家名/年份/单位/缺失；
2. 机制模型：弹性/引力/Armington/局部均衡/情景反事实；
3. 分问：贸易再分配、产业链、政策工具、财政收入、综合评价；
4. 稳健性：参数±、情景、替代数据源。

**2025 C 题的真实坑**（可迁移）：

- 进口表可能是“运保费”不是货值；直接当货值用会全盘错——附件字段名义 ≠ 内容，先实测核对再建模（审计规程见 `16`）；
- 2025 列可能全 0，关键政策期要补月度数据；
- HTS 8 位→2 位映射、MFN/FTA/301/232/对等关税叠加规则要写清；
- 五问不要五套割裂模型；用同一组弹性/情景贯穿。

**可迁移的加分手法**：

- 题内历史政策冲击是现成自然实验（2018–19 贸易战→DID/事件研究校准弹性），胜过照抄文献参数；
- 题面给的数字是建模暗示（“46% 进口车”暗示拆渠道；锚点变化暗示先复现已知段再外推）；
- 单边官方数据缺口用伙伴国镜像补（对方海关、UN Comtrade），题面允许外部数据就大胆补；
- 题面未定义的类别（“高中低端”）自定义并给分层依据——这是区分点不是负担。

**得分点**：数据正确性、机制自洽、反事实/情景、英文可视化、政策结论。
**坑**：只做描述统计；五问全做但每问浅；关税叠加写错；拿运保费当货值。

## 3.5 D 题：运筹/量子优化

典型链路：

1. 经典 UC/MIP：目标、功率平衡、上下限、最小开停机、爬坡；
2. 扩展：直流潮流、N-1、备用；
3. QUBO 转化：罚函数、二值编码；
4. 规模缩减：位宽/分组/时段解耦；与经典解对比。

**得分点**：经典模型正确、QUBO 转化透明、规模/比特数论证、经典 vs 量子对比。
**坑**：现场学 SDK 时间不够；罚函数权重无依据；规模缩减没有可行性论证。

**规则**：

1. 只选一题；不要四题都做。
2. 先排除“数据拿不到/背景完全不懂”的题。
3. C 题若选，D1 必须完成数据管线；否则换题要果断。
4. 读题时标记四件事：显式分值、指定工具/SDK、非技术信件要求、“collect your own data”——它们直接决定工作量分配与分工。
5. 选题后把题号写进 `赛事参数.md`，全文/文件名统一。
